# LZ Store
Site estático pronto para GitHub + Vercel.

## Publicar
1. Suba todo o conteúdo desta pasta para a raiz de um repositório GitHub.
2. Importe o repositório na Vercel.
3. Framework Preset: Other.
4. Deploy.

## Editar produtos
Edite `config.js`. Todos os preços, nomes, imagens e tamanhos estão lá.

## Imagens
As imagens do catálogo ficam em `assets/products/` e já são PNG com fundo transparente.
